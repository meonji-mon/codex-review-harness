# 공통 지침 한국어 참고 요약

**참고용이며 정본이 아닙니다.** [AGENTS.md](../AGENTS.md)와 연결된 영어 문서가 정본입니다. 이 요약으로 조건·의무·예외를 바꾸거나 완화하지 않습니다.

- Astra 메인은 직접 판단·계획·구현·검증합니다. 하네스·Laya·preflight·계획 에이전트·cleanup_worker를 자동 관문으로 사용하지 않습니다. 다른 메인은 영어 적용표를 따릅니다.
- 역할은 책임·소유권·권한, 모델·effort는 실행 선택입니다. Claude·Grok은 해당 작업·역할의 사용자 선택 범위에서만 사용하며, 메인 선택이 다른 서브 선택을 뜻하지 않습니다. Claude Sonnet·Opus는 특정 업무에 고정하지 않습니다. Grok은 지시문 작성에만 사용합니다.
- 기본은 메인 직접 실행입니다. 위임은 위험·모호성·소유권·필요성 순으로 판단합니다. 일반 수정·지침 변경·모델 등록·점수 평가만으로 에이전트를 호출하지 않습니다.
- 작은 작업은 도구 전 한 문장 계획, 복잡·고위험은 목표·범위·순서·검증 네 줄입니다. 승인 불필요 작업은 설명 후 바로 실행합니다.
- 승인은 실행 위치보다 실계정·데이터·금전·메시지 부작용으로 판단합니다. 침묵은 승인이 아니며 같은 승인 범위는 재확인하지 않습니다. TestFlight·Notion·정리 상시 승인의 정확한 범위는 영어 본문을 따릅니다.
- 비밀·키·실제 개인정보와 기존 작업을 보호합니다. 실패·재시도·필요하나 미수행한 검사를 보존하며, 없는 결과·시간·비용·성능을 만들지 않습니다.
- 정리는 영어 6절의 범위·승인·제한을 따릅니다. `LocalHistory` 같은 복구 이력과 보호 경로를 포함하는 상위 폴더의 재귀 삭제도 막습니다. 자동 정리는 휴지통을 비우지 않으며 영구 삭제에는 별도 범위의 사용자 요청이 필요합니다. [정리 사용법](../guides/maintenance.md#cleanup-usage)에 따라 실제 사용·참조·복사본과 보호 판정을 확인합니다.
- 고위험·명시 검수는 필수입니다. 선택 검수는 구체적인 필요가 있을 때만 사용합니다. 검수자는 실제 read-only로 실행하되 메인 권한은 유지하며, 차단·필수 근거 부족을 임의 통과로 처리하지 않습니다.
- 프론트 변경은 실제 변경 전후 이미지를 표시하고 직접 조작합니다. 텍스트 확대는 요청 또는 관련 결함이 있을 때만 검사합니다.
- Android는 SDK/CLI와 독립 에뮬레이터만으로 가능한 작업이면 Android Studio를 열지 않습니다. 사용자 요청 또는 CLI로 처리할 수 없는 IDE 전용 필요가 있을 때만 이유를 설명하고 엽니다.
- 한국어 계획·보고는 유지할 수 있습니다. 요약을 바꾸면 영어 정본과 조건·예외를 대조합니다.
