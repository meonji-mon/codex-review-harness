# Browser usage

Use for web exploration, signed-in site operation, web UI checks, screenshots, forms, and click flows. Tool choice, exceptions, and approval: [section 5](../AGENTS.md#5-tools-accounts-and-security).

## Aside entry points

1. Aside MCP `exec`/`repl`.
2. Terminal `aside "…"` or `aside repl "…"` (`~/.local/bin/aside`).

Use `aside exec` or `aside "…"` for ordinary tasks; `aside repl` for DOM, screenshots, and numeric inspection. Resume/control sessions with `aside session resume|steer|queue|stop <id>`. Read the relevant Aside skill and use `aside guide` for the actual CLI contract.
